Open-source projects around Homematic, MQTT and Home Assistant.

Homematic

  • aiohomematic — async Python library for Homematic(IP) via OpenCCU, CCU3, CUxD and CCU-Jack
  • homematicip_local — Home Assistant integration for Homematic(IP)
  • openccu-loom — Go daemon bridging Homematic to MQTT, REST, MCP and Matter
  • godevccu — virtual CCU for testing

  • go-daikin2mqtt — Daikin ONECTA
  • go-homeconnect2mqtt — Home Connect, local
  • go-keba2mqtt — KEBA KeContact P40
  • go-mtec2mqtt — M-TEC Energybutler
  • go-unifi2mqtt — UniFi Network
  • go-zendure2mqtt — Zendure
  • go-raumfeld-connect — Teufel Raumfeld
